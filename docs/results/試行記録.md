## 記入ルール

- **正答性**: 1.0（完全一致）/ 0.5（漏れ・誤検出が軽微、または部分回答）/ 0（実体を外した・幻覚あり）。Q4 は点数の代わりに「列挙数/142」を記載。
- **トークン**: セッション開始直後と回答完了後の `/cost`（または `/context`）の差分。Claude Code のみ記録し、Copilot は「-」のまま。
- **フォールバック**: 指示に反して内蔵 Grep/Read を使ったら「あり」とし、その試行は参考値扱い（やり直し推奨）。
- 実施順は「ツールごとに MCP 設定を切り替え → Q1〜Q6 を各3回」。**クエリごとに新規セッション**とする。
