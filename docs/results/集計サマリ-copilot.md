# 集計サマリ（GitHub Copilot）

[試行記録.md](試行記録.md) の Copilot 分から、クエリ×ツールごとに**3試行の中央値**を転記する。  
Copilot はトークンを直接確認する手段がないため、トークン欄は「-」とし呼出回数・所要時間で比較する。  
判定の目安・結論のまとめ方は [比較検証.md](../比較検証.md) の「判定の目安」を参照。

## エージェント間差分の所見

[集計サマリ-claude-code.md](集計サマリ-claude-code.md) と両方揃ったら、同一ツールのエージェント間差分（正答性・呼出パターン）をここにまとめる。  
差が大きい場合、それは MCP サーバの性能差ではなくエージェント側のツール呼び出し戦略の差である。
