## 採点上の注意

- B は上記21個に対する再現率・適合率で採点。static 関数（prv〜）を混ぜてきたら「公開関数」の指定に反するため誤検出。
- 「全部外れる（ファイル全体が #if 内）」という構造を指摘できているかを備考に記録する。
- なお timers.c:42 に `#if ( INCLUDE_xTimerPendFunctionCall == 1 ) && ( configUSE_TIMERS == 0 )` → `#error` があり、この組み合わせはビルド不能。ここまで言及したら加点級の備考。
- Serena（プリプロセス済みビュー）は「configUSE_TIMERS=1 の構成しか見えない/0 側は不可視」という答え方になる可能性がある。答え方の質の違いを備考に必ず記録する。
